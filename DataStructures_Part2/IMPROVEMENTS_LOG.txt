IMPROVEMENTS MADE TO REGISTER AMBULANCE FUNCTION:
═══════════════════════════════════════════════════════════════════════════

✅ 1. AUTO-GENERATED AMBULANCE ID
   ────────────────────────────────────────────────────────────────────────
   BEFORE: User had to manually enter ID without knowing the format
   
   AFTER:  
   - System auto-generates next ID based on current count
   - Format: A001, A002, A003, etc. (A + 3-digit number)
   - User can choose:
     Option 1: Use suggested ID (quick & easy)
     Option 2: Enter custom ID (for flexibility)
   
   BENEFIT: Users know the correct format and can register quickly

   BENEFIT:

   - Still flexible for adding new drivers
