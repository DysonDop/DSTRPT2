✅ MODULE 4: AMBULANCE DISPATCHER (Implemented)
   - Role: Schedules hospital ambulances for continuous duty
   - Data Structure: Circular Queue
   - Files: AmbulanceDispatcher.h, AmbulanceDispatcher.cpp
   
   Functionalities:
   1. Register Ambulance - Add ambulance to active duty queue
   2. Rotate Ambulance Shift - Rotate schedule (front to back)
   3. Display Ambulance Schedule - Show all ambulances in order
   
   Why Circular Queue?
   - Ambulances need continuous rotation (circular behavior)
   - Ensures fair distribution of duty time
   - When ambulance completes duty, moves to back of queue
   - O(1) time complexity for rotation operations

HOW TO INTEGRATE YOUR MODULE:
──────────────────────────────────────────────────────────────────────────

STEP 1: Create Your Header File (YourModule.h)
───────────────────────────────────────────────
   - Define your data structures
   - Declare your class and functions
   - Follow the same pattern as AmbulanceDispatcher.h
   
   Example structure:
   
   #ifndef YOUR_MODULE_H
   #define YOUR_MODULE_H
   
   // Your data structures
   struct YourDataType { ... };
   
   // Your class
   class YourModule {
   private:
       // Private members
   public:
       // Constructor
       YourModule();
       
       // Your 3 required functions
       void function1();
       void function2();
       void function3();
   };
   
   // Menu function (will be called from main)
   void yourModuleMenu();
   
   #endif


STEP 2: Create Your Implementation File (YourModule.cpp)
─────────────────────────────────────────────────────────
   - Include your header file
   - Implement all class methods
   - Implement the menu function
   - Follow AmbulanceDispatcher.cpp as a template


STEP 3: Update Main Program File (DataStructures_Part2.cpp)
────────────────────────────────────────────────────────────
   a) Add your header file:
      #include "YourModule.h"
   
   b) Uncomment the function call in the appropriate case:
      case 1: patientAdmissionClerkMenu(); break;
      case 2: medicalSupplyManagerMenu(); break;
      case 3: emergencyDepartmentOfficerMenu(); break;


STEP 4: Update Visual Studio Project Files
───────────────────────────────────────────
   a) In DataStructures_Part2.vcxproj, add:
      <ClCompile Include="YourModule.cpp" />
      <ClInclude Include="YourModule.h" />
   
   b) In DataStructures_Part2.vcxproj.filters, add:
      <ClCompile Include="YourModule.cpp">
        <Filter>Source Files</Filter>
      </ClCompile>
      <ClInclude Include="YourModule.h">
        <Filter>Header Files</Filter>
      </ClInclude>


STEP 5: Test Your Module
─────────────────────────
   - Compile the entire project
   - Test each functionality
   - Ensure menu navigation works properly
   - Test with sample data
